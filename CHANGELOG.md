## [1.0.0] - 2026-10-08

First Android release of the bad-habit interval tracker.

### Added

- Track habits as intervals between slips: each interval must beat your best so far, or (set in Settings) the one right before it.
- Habit detail with a live clock, interval chart and history; log a slip with optional triggers and a note.
- Stats: pass rate, fails, slips this week and the last 8 intervals per habit.
- Notifications when you beat your bar, 30 minutes before you would, and an optional 9:00 daily summary.
- Four home-screen widgets: ring, streak, quick log, and all habits with tap-to-log.
- Delete a habit, export history as CSV, and reset all intervals.
- Update check against GitHub releases, with the installed version shown in Settings.
